Formulas

Exact solution:

VBB = VCC * R2 / (R1 + R2)
RB  = R1 * R2 / (R1 + R2)
IB  = (VBB - VBE) / (RB + (1 + beta) * RE)
IC  = beta * IB
IE  = (1 + beta) * IB
VE  = IE * RE
VC  = VCC - IC * RC
VB  = VBE + VE
VCE = VC - VE

Beta-independent approximation:

VE  ~= VBB - VBE
IE  ~= VE / RE
IC  ~= IE
VCE ~= VCC - IC * (RC + RE)

Valid when beta * RE / RB ≥ 10. The approximation assumes the active region and is shown for comparison only.
